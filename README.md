## 🎯 Цель проекта

### Бизнес-цель

Создать быструю и эффективную систему сбора обратной связи от клиентов Arenadata для:

- ⏱️ Снижения времени реакции на критические проблемы клиентов
- 📈 Улучшения качества продукта за счёт структурированного фидбека
- 😊 Повышения удовлетворённости клиентов за счёт быстрого ответа
- 🤖 Автоматизации сбора и обработки обращений вместо ручного сбора через почту/мессенджеры

### Техническая цель

Реализовать **MVP (Minimum Viable Product)** за 2 недели с базовым функционалом:

- Приём отзывов через веб-формы
- Автоматическая классификация по срочности
- Уведомления команды о критических проблемах
- Админ-панель для анализа данных

### KPI системы

| Показатель | Целевое значение |
|---|---|
| ⏱️ Время реакции на критические отзывы | не более 1 часа |
| 📊 Уровень автоматической классификации | точность по ключевым словам |
| 📉 Снижение количества "потерянных" обращений | все отзывы в одной системе |
| 📈 Прозрачность обработки | статусы, метрики, аналитика |

## ❓ Проблема, которую решает проект

| Без такой системы | С системой |
|---|---|
| ❌ Клиенты пишут в разные каналы (почта, Telegram, звонки) | ✅ Все обращения в одном месте |
| ❌ Критические проблемы могут быть пропущены | ✅ Автоматическое определение срочности |
| ❌ Нет единой статистики и аналитики | ✅ Уведомления команде в реальном времени |
| ❌ Сложно оценить эффективность поддержки | ✅ Полная аналитика и отчёты |

## 📋 Описание проекта

Backend‑сервис, который **собирает обратную связь от клиентов и автоматически обрабатывает её**.

1. Пользователь заполняет форму (техническая, бизнес или Executive)
2. Система анализирует текст и автоматически определяет срочность (high/medium/low) и категорию проблемы
3. Критические отзывы отправляются команде в Telegram и Email
4. Администратор отслеживает все обращения и анализирует через SQLAdmin

## ⚡ Ключевой функционал

### 1. Автоматическая классификация

- Анализ текста отзыва по ключевым словам
- Определение срочности: high / medium / low
- Категоризация: bug, api, performance, ui_ux, feature_request
- Расчёт приоритетного балла (0-100)

### 2. Уведомления

- 📨 Telegram — мгновенные уведомления о критических отзывах
- 📧 Email — подтверждение получения + уведомления команде
- 🔗 Magic Link — вход без пароля

### 3. Админ-панель

- 🖥️ SQLAdmin — управление данными через веб-интерфейс
- 🗄️ Adminer — полный SQL-доступ к БД
- 📋 Готовые SQL-запросы для отчётов

### 4. Динамические формы

| Форма | Для кого |
|---|---|
| /form/tech | Технические специалисты |
| /form/business | Бизнес-пользователи |
| /form/exec | Руководители |
